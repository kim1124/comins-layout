## 변경과 근거

### 레이아웃 동기화

- GridStack의 위젯별 `update()`는 배치 중에도 이전 좌표와 충돌하므로, 삭제 후 자동 정렬에서 widget-1과 widget-7의 위치가 뒤바뀌었다. 전체 좌표를 공개 `load(..., false)`로 적용해 기존 HTMLElement와 React 콘텐츠를 유지한다. 전달 객체는 새로 만들어 GridStack의 입력 정규화가 React 상태를 변경하지 않도록 했다.
- `load()`가 자신의 배치를 종료하므로 소비자가 연 배치가 끝날 때까지 동기화를 지연한다. 해제 전에는 중간 상태를 커밋하지 않고, 종료 후 최신 옵션을 적용하며 unmount 때 예약 프레임을 해제한다.
- 삭제·Float 비활성화 등의 엔진 보정 결과가 입력과 다르면 React에 한 번 반영한다. 이미 일치하는 스냅샷은 다시 커밋하지 않는다. 외부 드롭 미리보기와 활성 드래그의 중간 커밋 방지 경로를 유지했다.
- Float 옵션은 배치를 열기 전에 변경한다. GridStack은 배치 시작 시 Float 값을 기억하고 종료 시 복원하기 때문이다.
- GridStack 저장 결과에서 최소 너비·높이와 같은 값은 생략된다. 이때 1로 해석하던 부분을 `minW`/`minH`로 복원하도록 수정했다. 제거한 제약 조건도 다음 동기화에 반영한다.

### Size To Content

- 측정 대상인 위젯 Shell의 `height: 100%` 때문에 현재 위젯 높이를 다시 측정하던 문제였다. 콘텐츠 크기 맞춤 모드에 한해 intrinsic height를 사용하며 헤더 높이도 포함한다.
- 위젯별 크기 맞춤 설정 변경 시 엔진 옵션과 측정 클래스를 함께 갱신한다. 전역 옵션, 개별 `false`, 최소·최대 높이 및 `refresh()` 재측정을 확인했다.
- 최대화·최소화 중에는 크기 맞춤을 중단하고 복원 후 재개해 사용자가 요청한 크기와 자동 측정이 충돌하지 않게 했다.
- 드래그 중 `refresh()`가 호출되어도 React 커밋은 드래그 종료까지 지연한다.

### 모바일 및 안내

- Mobile Touch 예제는 640px 이하 컨테이너에서 3컬럼을 사용한다. 390px 화면에서 첫 위젯 너비 354px, 제목 너비 33px로 확인했으며 제목과 세 동작 버튼이 잘리지 않는다.
- 핸들 표시 토글의 해제 값을 명시적인 `false`로 바꾸고 표시 상태를 설명하는 이름을 적용했다. 터치 환경의 실제 엔진 값이 `true → false → true`로 전환된다.
- GridStack의 조상 드래그 핸들이 버튼 `touchstart`를 취소해 탭 클릭이 발생하지 않았다. 위젯 동작 영역에서 native touch 전파를 중단하되 기본 탭 동작은 유지하고, 컴포넌트 정리 시 리스너를 해제한다. 실제 `tap()`으로 삭제를 확인했다.
- Breakpoint 기본 기준을 Grid 컨테이너 너비로 명시했다. `none`은 비례 변환을 생략하지만 컬럼 경계와 겹침은 보정하며, 넓어질 때 기존 컬럼별 배치를 복원한다.

### 직접 조작 재확인

테스트 실행과 별도로 실제 브라우저에서 삭제·저장, 한 번의 자동 정렬, native pointer 리사이즈 후 콘텐츠 크기 맞춤 활성화, 모바일 표시 토글 및 버튼 탭을 다시 조작했다.

- 저장 JSON, React 좌표, 엔진 좌표가 모든 잔여 위젯에서 일치했다.
- 자동 정렬 후 widget-1 `(0,0)`, widget-7 `(0,2)`를 포함한 전체 순서가 맞았다.
- 콘텐츠 크기 맞춤은 H4에서 H2로 축소됐고 React와 엔진 높이가 일치했다.
- 모바일 핸들 표시 설정이 실제로 변경됐으며 첫 위젯 삭제 탭이 동작했다.
- 직접 조작한 별도 페이지의 console error / page error는 0건이었다. 수정 후 화면도 확인했다.

### 중간 실패와 처리

- 변경 전 삭제·정렬 상태 불일치와 모바일 컬럼 문제를 새 회귀 테스트에서 확인했다. 초기 Float·Size To Content 테스트는 잘못 작성한 버튼 이름 때문에 실패했으므로 제품 재현 증거에 포함하지 않았다.
- 구현 중 Float 배치 순서, 위젯별 크기 맞춤 클래스, 최소 크기의 저장 생략 처리, 모바일 탭, 드래그 중 refresh 커밋을 각각 실패 결과와 소스로 확인한 뒤 수정했다.
- 기존 제목 더블클릭 테스트의 fixture는 아래 행의 위젯이 실제로 첫 행으로 압축되지만 React에는 남아 있는 불일치에 의존했다. 아래 행을 전체 너비로 만들어 실제 빈 공간이 존재하도록 고치고 엔진 좌표 assertion을 추가했다. 기존 확장 기대값은 유지했다.
- 기존 반응형 안내 assertion은 수정한 문구에 맞췄다.
- 최종 브라우저 검증 최초 시도는 샌드박스의 `listen EPERM`으로 서버가 시작되지 않았다. 로컬 포트 실행이 허용되는 환경에서 동일 검증을 실행해 통과했다.
