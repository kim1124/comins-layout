### 원인 및 기능 경계

- A GridStack 위젯을 B GridStack으로 이동·복사하는 기능은 이미 `/examples/advanced/multi-grid/horizontal`과 vertical route의 `TransferPlayground`에 구현되어 있다. `gridId`, `acceptExternalWidgets`, `gridTransferMode`, `onWidgetDropRequest`, `transferDashboardWidget`의 제어 상태 경로를 사용하며 실제 pointer drag와 버튼 대안을 제공한다.
- Nested Grid는 Root/Child/Grandchild React 상태 소유권과 중첩 interaction 경계를 설명하는 예제다. 같은 Grid 내부 layout 이동과 A→B Grid 전송은 서로 다른 계약이므로, Nested 설명과 컨트롤 영역에서 다중 Grid 전송 예제로 연결했다.
- 휴지통 드롭 기능은 hidden `/__test__/advanced` fixture와 `/readme-demo?feature=external-drop`에는 남아 있었지만 0.2.1 메뉴 통합 후 전용 public Playground route가 없었다. 기능 제거가 아니라 공개 route 누락이 원인이었다.
