## 변경 요약

- API DOC, Playground 한·영 안내, 사용자 가이드의 용어와 동작 설명을 일치시킴.
- Static Grid는 엔진 드래그·리사이즈 차단이며 앱 전체 읽기 전용이 아님을 명시.
- Size To Content는 기본 비활성인 선택 기능으로, `cellHeight`가 아닌 위젯 행 수 `h`를 조정함을 명시. 예제의 활성 초기 상태와 패키지 기본 동작을 구분.
- Responsive `none`은 반응형 해제가 아닌 비례 변환 생략 전략이며 경계·겹침 보정과 컬럼별 배치 복원이 적용됨을 명시.
- 지연 렌더링의 최초 표시 지연, 저장 예제의 메모리 범위, 이벤트 호출 순서, 상태 변경 종류, 정렬·너비 채움, 전송 ID, 외부 드롭, 공개 핸들 메서드의 의미를 보완.
- 위젯 이벤트 로그의 표시 이름을 실제 공개 API인 `onTitleDoubleClick`으로 통일.
- 발췌 코드임을 안내하고, 공통 화면 제목을 `예제 컨트롤` / `실행 예제`로 정리.
- 예제 메뉴 삭제, 기능 기본값 변경, 패키지 실행 코드 변경은 이번 설명 개선에 포함하지 않음.

### 변경 내용

- Size To Content의 측정용 shell은 intrinsic height를 유지하고, 배경·테두리·그림자는 실제 할당된 grid item content 영역에 표시하여 리사이즈 핸들 이탈을 수정했습니다. 강제 높이 확장으로 콘텐츠 축소 측정을 방해하지 않습니다.
- 활동 내역 추가·삭제·초기화, 자동 높이 토글, 현재 항목 수와 `h` 표시를 갖춘 전용 콘텐츠 높이 예제를 추가했습니다. `refreshKey={count}`로 콘텐츠 변경만 재측정하며, 고정 높이·수동 리사이즈와의 차이를 설명합니다.
- Static Grid는 레이아웃 잠금 페이지의 잠금 방식 선택으로 통합했습니다. 기존 `/examples/advanced/static` 주소는 통합 페이지로 연결하며 canonical 메뉴는 24개입니다. 설정 표에는 정적 모드를 반영한 실제 이동·리사이즈 가능 여부를 표시합니다.
- API 문서를 기능 목차, 설명, 직접 실행, 최소 적용 코드, 접을 수 있는 상세 API 순서로 정리했습니다. 각 Props/Methods/Events 항목에 관련 실행 예제를 연결하고 동일한 Playground route를 `embed=1`로 재사용합니다. 한 번에 하나만 실행하며 종료·전환 시 기존 iframe을 제거합니다. 문서 내부 한국어 예제는 사용자의 Playground 언어 저장값을 덮어쓰지 않습니다.
