## 원인과 최종 수정

- Controlled column 전환 중 6-column interaction snapshot을 12-column으로 다시 표시해 12-column cache를 덮어쓸 수 있었다. `DashboardGrid`와 GridStack adapter가 현재 controlled column과 다른 non-responsive snapshot을 stale로 폐기하도록 수정했다. Responsive column callback 경로는 유지했다.
- Layout과 Advanced가 full-state validator를 중복 구현하면서 malformed supported cache 하나를 전체 snapshot 실패로 처리했고, Layout은 widget metadata type을 충분히 검증하지 않았다. 두 route가 공유하는 example-only `state-snapshot.ts` sanitizer를 도입했다.
- Shared sanitizer는 top-level columns/widgets/layout IDs·finite geometry/restore maps/metadata를 fail-closed 검증한다. Unsupported cache key는 무시하고 malformed supported-column entry만 개별 폐기하며, 유효한 top-level active state와 다른 유효 cache는 보존한다.
- Advanced automatic engine query 성공 시 initial not-ready status를 ready 상태로 바꾸고, Widget/Layout/Advanced header에 route 목적 설명을 추가했다.
- Public runtime API/type, dependency, lockfile, package version, one-hook/one-grid route ownership, adapter isolation은 변경하지 않았다.
