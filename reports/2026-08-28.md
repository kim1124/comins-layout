# 2026-08-28 Playground UI 정합화

## 작업 일시

- 2026-08-28 KST

## 요약

- Grid Layout Playground 셸을 현재 Data Table Playground와 동일한 `64px` 상단 헤더, 좌측 Sidebar, 중앙 스크롤 콘텐츠 구조와 시각 토큰으로 정합화했다.
- Playground 1차 메뉴는 `위젯`, `레이아웃`, `고급 예제` 세 개만 노출한다.
- 위젯 3개, 레이아웃 5개, 고급 예제 19개의 기능별 서브 메뉴를 연결했다.
- 기존 Transfer 구현과 `/examples/transfer` direct route는 보존하되 Playground 메뉴에서는 노출하지 않았다.
- 상단 언어 토글과 3개 메뉴 검색 UI를 Data Table Playground 구조에 맞춰 추가했다.
- 모든 Widget 예제에 `Title {n}` / `Content {n}`과 리사이즈 잠금, 이동 잠금, 삭제 action을 공통 적용했다.
- Widget 이벤트의 move, resize, title double-click에 실제 `before / action / after` 공개 callback을 추가했다.
- Layout의 컬럼 변경, 잠금, 전체 상태 저장/복원, 자동 정렬/빈 공간 채우기, semantic mutation event 예제를 분리했다.
- GridStack 공식 Demo 목록을 기준으로 responsive, lazy load, nested, RTL, size-to-content, static, transform, multi-grid 예제를 구성하고 마지막에 안전한 공개 핸들러/메서드 예제를 배치했다.
- `getColumnCount`, `getRowCount`, `getFloat`, `isAreaEmpty`, `willItFit` read-only handle과 `onLayoutMutation` observer를 공개 계약에 추가했다.
- 공통 예제의 타이틀 전용 drag 제한을 제거하고, 명시적인 `타이틀 Drag Handle` 예제에만 해당 제한을 유지했다.
- 제어형 Nested `DashboardGrid`가 GridStack native sub-grid 이벤트 라우팅에 편입되지 않도록 소유권을 분리하고, 상위 Grid 초기화가 하위 위젯 위치 스타일을 제거하지 않도록 직접 자식 범위로 제한했다.
- 모든 Playground 토글이 `aria-pressed="true"`일 때 민트 배경, 초록 테두리와 아이콘·텍스트 색상으로 상태를 표시하도록 공통 스타일을 적용했다.
- 셸에만 머물던 언어 상태를 공통 locale provider로 예제 트리에 전달하고, Widget·Layout·Advanced·다중 Grid의 버튼, 설명, 콘텐츠와 접근성 레이블을 한·영 전환하도록 보완했다.

## 결과

- 데스크톱과 좁은 viewport 모두 Data Table Playground와 동일한 셸 배치를 사용한다.
- 세 메뉴, 27개 서브 메뉴의 active route 표현과 검색 이동이 동작한다.
- 요청된 Widget/Layout 예제와 공식 Demo 기반 고급 예제가 각각 독립 URL에서 동작한다.
- 레이아웃 상태는 React controlled source of truth와 serializable snapshot 경계를 유지한다.
- Playground route 전환 시 기존 owner unmount 계약을 유지한다.
- Widget 3개, Layout 5개, Advanced 19개와 `/examples/transfer` 호환 경로에서 의도된 잠금 예외를 제외한 이동·리사이즈 계약을 확인했다.
- Widget 토글의 `aria-pressed` 상태와 민트 배경·초록 테두리 계산 스타일이 함께 전환된다.
- Layout 잠금, 셀 높이, Advanced 기능, 다중 Grid 모드 등 모든 예제 토글이 동일한 활성 상태 스타일을 사용한다.
- 영어 전환 시 공식 메뉴의 27개 예제와 `/examples/transfer` 호환 경로에서 제목, 설명, 버튼, 위젯 action, 이벤트·상태 레이블 및 다중 Grid 콘텐츠가 동일 locale로 즉시 전환되고 재탐색 후에도 유지된다.

## 잔여 이슈

- `/examples/transfer`는 기존 작업 보존을 위해 direct route로만 남아 있으며 메뉴 active 항목은 없다.
- 공식 GridStack의 raw dynamic nested mutation 대신 named controlled nested grids를 사용했다. raw `subGridDynamic` 노출은 별도 공개 상태 계약이 필요하다.
- 현재 Playwright 프로젝트 매트릭스에 WebKit/Safari는 없으므로 Safari는 미검증 경계다.
- Release Candidate 준비 전까지 commit, push, PR, publish는 수행하지 않았다.
